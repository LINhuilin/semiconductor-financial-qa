## 更新仓库
下载并解压本修改包，将 semiconductor_qa 内的内容放在仓库根目录。不要上传 index.pkl、未压缩chunks.json、环境文件或密钥。压缩库单文件低于网页上传25MB限制。运行 python index.py 后 python app.py 即可使用随包压缩库。旧evaluation/extractive目录保留为历史测试，当前修改证据以evaluation/revision为准。

## 自行复跑
```powershell
python -m pip install -r requirements.txt
python index.py
python -m unittest discover -s tests -v
python evaluation/evaluate_retrieval.py
python evaluation/evaluate_http.py
python app.py
```

HTTP评价脚本只需项目依赖，不要求浏览器。浏览器测试另需playwright Chromium，可运行 python -m playwright install chromium 后把实际可执行路径传给 --browser。
