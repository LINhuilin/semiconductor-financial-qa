## 能确认的原始依据

依据改动前仓库README.md（可用git show HEAD:README.md查看），未发现独立教师任务书、评分表或课程附件。下面是其原文，区分明确文字与解释：

- “默认运行原文检索：无需API，展示候选证据及页码，不能冒充生成式回答。”——要求类型如实标识，未明确说检索或抽取式一定不能提交。
- “配置生成模型后运行问答：使用兼容 /chat/completions 的模型服务，按服务商说明设置变量”——描述生成问答阶段；若教师要求完成此阶段，规则抽取不满足，但这段并非教师评分条款，也不要求必须用付费OpenAI。
- “若课堂要求预训练嵌入，使用下列命令升级”——是条件要求，不能直接当作无条件必须。
- “按evaluation/questions.csv逐题运行。测试表中的标准答案、标准页码先人工从原PDF核验。填写召回内容、答案、正确性、引用正确性和失败原因；不可仅据模型输出评判模型。”
- “保留至少2道跨公司全景题。”
- “提交代码仓库、截图、10题记录和一页结论。”
- “补充财报官方URL；不要提交API密钥。”

目前完成了方案A的实现及真实10题抽取式测试、2道跨公司题、评价表、截图和结论。尚未完成官方来源核验、用户人工参考答案复核、教师验收、生成式回答或预训练神经嵌入；没有为这些项目预填通过。新增评价文件尚未推送到GitHub。

## Windows本地运行

Python3.11或3.12，在项目目录打开PowerShell。无需设置QA变量；已有QA_API_KEY等变量也不会让网页自动调用API。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe build.py
.\.venv\Scripts\python.exe index.py
.\.venv\Scripts\python.exe app.py
```

浏览器打开 http://127.0.0.1:8501 。用Ctrl+C关闭服务。磁盘包若已包含data/chunks.json，可跳过build.py；仍建议在自己电脑执行index.py，不加载不同版本或不可信来源的pickle。8GB内存、2GB独显不需要运行大模型，仍建议关闭不必要应用以留出建索引内存。Windows命令未在用户电脑实际执行；本次运行验证在Linux云环境完成。

生成的chunks.json、index.pkl和__pycache__已忽略；不要提交密钥。build.py会重写data中的清单和提取错误记录，替换财报前应保留自己的资料。

## 本次测试如何复现

规则与计算边界：

```text
python -m unittest discover -s tests -v
```

实际网页评价需额外安装playwright并提供Chromium，仅用于测试，不是应用依赖。本次使用云环境已有Playwright和/usr/bin/chromium，应用依赖来自独立venv；尝试在venv额外安装Playwright被网络代理403阻止，因此使用已安装的系统工具完成全部真实网页检查，没有关闭TLS验证。已验证的云端命令：

```bash
PYTHONPATH=/workspace/.environment/semiconductor-financial-qa/venv/lib/python3.12/site-packages python3 /workspace/semiconductor-financial-qa/evaluation/test_extractive_web.py --runtime /workspace/.environment/semiconductor-financial-qa/runtime --browser /usr/bin/chromium --output /workspace/semiconductor-financial-qa/evaluation/extractive
```

脚本启动独立动态端口的测试进程，在进程中禁止urllib外部API调用；逐题点击网页后保存响应并进行检查，结束后关闭它启动的服务。参考答案位于evaluation/reference_answers.json，与生产问答逻辑分离；引用检查直接读取PDF，而非只相信模型或应用返回的引用。生成式测试次数为0。当前结果和应用文件哈希、源PDF哈希、时间记录于summary.json。

- questions.csv：10题召回ID、实际系统回答、参考答案/页码、正确性、引用正确性及错误原因。
- web-responses.jsonl：10次实际网页完整响应（含召回片段、抽取事实和来源）。
- results.json、summary.json：逐题检查依据、总体结果及源文件哈希。

- downloaded-question-10.json：实际点击页面下载按钮获得的拒答记录。
- 结论.md：一页阶段结论。
